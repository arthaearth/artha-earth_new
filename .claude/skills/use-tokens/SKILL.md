# Токени

- Токен — значення з назвою за роллю (`accent`, `ink`, `surface`), не за виглядом (`blue`, `gray-200`).
- Значення кольорів, шрифтів, радіусів, пропорцій і відступів живуть **лише** в блоці `@theme` у `src/app/globals.css`. Решта коду посилається на токени за іменами.
- `line` — для декоративних ліній (розділювачі, рамки карток). Межа поля форми чи кнопки без заливки належить інтерактивному елементу: видима (≥ 3:1), колір `ink-muted`, не `line`.
- Не використовуй дефолтну палітру Tailwind (`blue-500`, `zinc-100`) і довільні значення (`[#abc]`, `p-[13px]`).
- Новий токен: додай у `@theme`, опиши роль у `CLAUDE.md`, перевір контраст текст/фон ≥ 4.5:1 (великий текст ≥ 3:1).
- Тем лише одна. Медіазапит темної теми й змінні `--background`/`--foreground` з create-next-app не повертаємо.
